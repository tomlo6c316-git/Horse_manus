# HKJC 賽馬預測引擎重設版（保留原Streamlit介面）

## 這一版改了甚麼

本版本保留原App的Streamlit頁面和賽日操作方式，主要重設預測引擎及資料安全邏輯：

- **WIN排序器**：新增LightGBM LambdaRank，以「同場頭馬排序」為目標，並用驗證期溫度參數轉成每場合計100%的概率。可選Fixed與Dynamic。
- **PLACE排序器**：新增Fixed及Dynamic的單馬入位模型，與WIN模型分開選擇Form。
- **位置Q/QP排序**：可選PLACE概率前兩匹組合，亦可試用直接以「兩匹同時按該場名額入位」為目標的QP雙馬排序器。直接QP排序器是實驗選項，不代表已有穩定優勢。
- **嚴格賽日前歷史統計**：馬、騎師、練馬師、組合、上仗、同場地及同路程統計只用目標賽日前的資料；同日及未來賽果不納入。
- **分開歷史價與即時盤**：過去日期的repo預測CSV會保留檔案內WIN／PLACE價供回測，介面明確標示為「存檔價、非即時報價」並停用刷新／凍結；今天或未來賽卡則不信任CSV舊價，須取得HKJC官方WIN／PLA實報才作即時預測。不會由WIN推算PLACE。
- **History故障時停止評分**：歷史大表無法讀取就不以預設勝率冒充完整模型輸入。
- **回測保護**：候選最終模型的訓練截止日為2026-10-28；App會排除同日及更早賽事，避免以最終模型回測它已學過的賽果。
- **派彩標示**：位置命中按有效出賽馬數的入位席位計算。WIN／PLACE只有結果檔有官方每$10派彩才計算收益與ROI；否則只報命中率。缺逐組QP官方派彩時不估QP ROI。最終賠率不會當作派彩。
- **防止單日過擬合**：移除用同一批賽果反覆挑最高ROI參數的尋優按鈕。

## 主要檔案

- `app.py`：保留原UI的重設版App。
- `hkjc_all_seasons_features.csv`：使用本次已整理、截至2026-10-28且排除2026-11-01賽果的History副本；App會逐賽事日期截斷。
- `win_ranker_redesign_20261110/`：Fixed/Dynamic候選模型、metadata及時間留出測試輸出。
- `train_hkjc_win_ranker.py`：可重現訓練及時間切分評估程式。
- `requirements.txt`：App／訓練依賴。

## Streamlit Cloud部署

1. 先將整個資料夾內容放進一個**新分支或測試repo**，不要直接覆蓋目前正式App。
2. 在Streamlit Cloud指定主程式為 `app.py`。建議選Python 3.12，並由 `requirements.txt` 安裝依賴。
3. App第一次開啟時，在左側選賽事日期，按「抓取排位並載入預測」。初次只嘗試抓第一場；其後選擇「當前操作／查看場次」，自動及手動更新都只向HKJC請求該一場。凍結中的場次不送更新請求。官方WIN/PLACE盤尚未開時，會顯示尚無有效盤口，不會用估算值補齊。
4. 賽事進行期間使用單場自動/手動更新。快照及模型分數應在開跑前收集；若要分析「某一時間下注是否有效」，須保留該時點的快照和時間，而不是只存最終盤。
5. **回測2026-11-01及之後賽事命中率**：左側「選擇Repo內的預測賽卡」先選對應日期的 `prediction_YYYYMMDD.csv`，再上傳該日包含 `賽事編號`、`馬號`、`名次` 的完賽結果CSV。App會按賽事編號＋馬號配對，並顯示WIN首選命中率、PLACE入位率及QP兩匹同時入位率。候選模型訓練截止日為2026-10-28，因此11月1日起可作時間外回測；不能用11月1日前已被最終模型學過的賽果宣稱外測。
6. 歷史預測CSV內的賠率只有在原始檔保存時點確實早於開跑、且未被賽後終盤價覆寫時，才可代表當時盤口。若CSV沒有快照時間戳，App會標明其為存檔價，不能證明它是例如「開跑前30分鐘」的報價；要測某一時點的實戰命中，應使用當時匯出的預測檔／Odds Snapshot。App會將預測卡WIN價與完賽CSV最終WIN價比對；高度一致時，因模型15項特徵包含WIN賠率、市場勝率和賠率排名，會顯示「事後資訊」警告。已查到repo的 `prediction_20261101.csv` 有效WIN價與完賽CSV最終價全部相同，故該日只能作事後診斷，不能代表真實賽前準確率。非出賽馬會按結果CSV未有正式名次剔除；若有效出賽馬缺模型分數，該場會排除並提示。
7. 要計算WIN回收，結果檔亦須有官方每$10獨贏派彩；PLACE需有每$10官方位置派彩欄（支援 `位置派彩`、`PLACE派彩`、`官方位置派彩`、`Place Dividend`、`place_dividend`）。QP若沒有逐組官方QP派彩，只顯示命中率。

### 關鍵限制

History中的獨贏賠率是官方終盤資料，並非有時間戳的賽前快照。因此上述市場排序與模型的市場特徵受終盤資訊影響，這份評估**不能當作「開跑前某一時點可下注」的精確回測，也沒有提供QP/PLACE實際ROI**。候選模型已用完整History重訓至2026-10-28；因此App會禁止用2026-10-28或更早的賽事對這些最終候選模型宣稱無洩漏的回測。後續要測真實落飛效益，從現在起持續保留多時間點官方WIN/PLACE快照、模型當輪分數、開跑時間、名次及官方派彩，累積新賽事外測。

## 使用建議

預設使用**純AI概率排序 + Fixed WIN排序器 + Fixed PLACE排序器 + PLACE前兩匹QP候選**，對應你設定的「每場WIN最高分首選」與「QP兩匹同時入位」評估目標；EV和最低賠率預設不會篩走馬匹。這只優先評估命中，不代表ROI最佳。每次賽後記錄命中與官方派彩，不要按同一批回測結果反覆調門檻。直接QP排序器、Dynamic版本及EV策略可另行比較；不保證預測命中或獲利。
